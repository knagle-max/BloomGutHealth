## 3. Binding Branding & UX spirit — implementation without interim approval

Use exact approved Bloom brand tokens, typography, icons, wordmarks, spacing, Everyday botanical green and Athlete dark navy/blue styling and established navigation. These contain **principles and concrete contracts**, not another blocking design-approval bureaucracy.

Codex's autonomous UI acceptance checklist for **materially touched surfaces**:
1. **Meaning before metadata.** Explain what the user is looking at, why it is relevant and what they can do; show exact units/date/source plus one material limitation nearby. Full scientific methods/provenance, evidence and original results remain accessible in 1–2 deliberate interactions—not deleted or technically buried.
2. **One obvious user job and primary action** on task entry screens: Today next step, Food capture→review→save, active Athlete current set, gut report view/manage/link, Genetics observed education, Progress comparable trends. A rich deep-dive view is not arbitrarily limited to a single card; avoid repeated heroes, unneeded dashboards and duplicated tabs.
3. **Real state, no theatrical precision.** Observed/self-reported/calculated/provider-category/research-only/unknown are distinct. Show per-report dynamic counts and actual corrected records, not sample fixtures. Zero ≠ missing; qualitative taxa ≠ quantified function; an opt-in food-report badge appears only when ranking materially changes.
4. **Easy source correction, control and recovery.** Real upload/review/correct/save/reload, clear report Delete and Link/Unlink, no hidden destructive actions, consent and opt-out visible, no loss of draft. User-safe errors, loading, empty-data and no-AI/no-wearable fallback.
5. **Contextual progressive disclosure.** First viewport understandable to ordinary users; technical scientist detail searchable/expandable for advanced users. No hardcoded '3–5' quotas, forced advice or repetitive scary disclaimers. Preserve full collections and modes. Warm, precise, unpressured language; no guilt/streak punishment, fear, microbe good/bad claims or excessive technical jargon.
6. **Brand consistency, not a redesign.** Reuse actual current React components/routes, existing design tokens and art; do only demonstrated deltas. Everyday and Athlete are distinct expressions of one Bloom identity; no separate AI/biology dashboard or new component framework by default.
7. **Functional responsive/accessibility checks.** Test relevant 320px/390px first viewport, 200% zoom/reflow, keyboard focus/labels, meaningful alt text/text diagrams, no clipped controls or nav obstruction, source/dialog return, light/dark and relevant Athlete appearance. Test actual save/restore and account boundaries, not screenshot-only appearance. For materially changed UI capture matched before/after exact-SHA screenshots selectively, not every commit.
8. **Codex makes design calls** when alternatives comply with this spirit; no interim Branding permission required. Record one-sentence rationale + impacted acceptance tests, then move on. Brand/UX specialists perform final integrated build review and can request concrete fixes at that gate.

**Design conflict precedence:** (1) factual source/safety/privacy/accessibility, (2) Product Owner's newest explicit decisions, (3) latest Architect-approved exact Brand UX contract, (4) established v1 tokens/assets, (5) Codex documented judgment.
