## Shared executable contract (applies to each source ID)
- Each row specifies **current verified code/dataset status**, authoritative discovery/acquisition location and release to pin, method, authentication/licence/cost state, existing canonical target, minimal delta, scientific QA, revision/withdrawal, fallback and acceptance. **A page URL is NOT a pinned dataset or right to redistribute.** Exact downloadable artifact and SHA-256 must be recorded from actual permitted acquisition, not guessed. “To pin/verify” means unresolved.
- Method shorthand: **server API** = bounded nonpersonal metadata API except authenticated own-account user sources; **bulk snapshot** = controlled immutable public reference download with atomic stage/activate; **user import** = consented owner-scoped original; **curated** = approved human-source excerpt/structured extraction. No private genetics/labs/Viome to external discovery.
- For every pilot produce `sourceId, authoritativeURL, edition, fetchedAt, bytes, sha256, licence+scope+reviewer, parserVersion, canonicalMappingVersion, acceptedCount, rejectedCount/reasons, matchedCount/denominator, missingCount, scientificReviewState, actionPermission, commitSHA, testRun, hostedSHA, actual capability, remainingUnknown`. Counts/versions are **UNKNOWN** until measured. No source-level percentage without a defined denominator.
- Enforce `materialStatus`, `identitySuitability`, `scientificUse` and `rightsByPurpose` independently; explain vs rank vs simulate independent. Every source refresh preserves old user observations and retracts only affected derived claim permissions. Do not install optional/research source solely to fill an inventory row.
- Existing canonical services remain owners of user data, food totals, labs, evidence, permission checks and action ranking; no second service, graph or datastore.
- Cross-cutting coverage report from **actual** canonical records: (1) food calories/macros/micros by source-nutrient-form-field and reportable food/item denominator, distinct measured zero vs unknown; (2) lab markers/raw panel vs reviewed interpretation/action denominators; (3) observed genetic call+quality vs reviewed genotype-eligible claim; (4) reported microbiome taxa vs verified rank/functional annotations; (5) food–substrate–enzyme–reaction–metabolite graph edges with complete chemistry/organism scope vs candidate edges; (6) reviewed nutrition/activity/lifestyle claims with positive, null/harm and tested action eligibility. Display counts **supported / partial / unavailable / unreviewed / ineligible**, no invented completeness.
- Stage independent CNF 2026/Canadian DRI/LOINC 2.83/UCUM pilots, preserve Food→Today and full-panel Response Intelligence P0, and parallel permitted molecular reference pilot. User-facing proof requires working existing app surfaces, not file download or fixtures alone.
