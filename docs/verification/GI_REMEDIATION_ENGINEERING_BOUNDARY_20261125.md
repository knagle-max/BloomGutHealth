## Implemented source and privacy boundaries

- `shared/gi-source-context.ts`: bounded typed self-reported GI context, event-time precision, condition assertions, actual-use status, source mutation metadata and separate medication/menstrual-pelvic investigation sharing scopes.
- `server/precision-storage.ts`: encrypted canonical writes/corrections; source and sharing revision comparison; account-bound idempotency; scrubbed same-row deletion marker prevents replay resurrection without changing allowed database kinds. Account clearing removes source records and the sharing revision. Generic context updates preserve privacy choices and cannot grant them.
- `server/precision-routes.ts`: existing authenticated/no-store router owns source access and strict commands. Server metadata cannot be supplied by clients. Source edits preserve existing measurements and stable context event IDs supplied with the corrected record.
- Existing Biology response form: optional GI capture, default-off sharing controls, source review and typed correction of existing symptom, bowel, medication/supplement, condition, warning, weight-loss and pelvic context. Complete typed context correction is supported by the owned source API; the UI preserves stable symptom/exposure/condition IDs, unrendered fields and reported time precision. Removing the final reported condition requires an explicit unknown/none-reported assertion. Absent sections/new events use the existing optional capture path; this does not create another tracker. No mandatory questionnaire. Existing female reproductive UI eligibility is retained; pelvic observations do not infer a cycle phase.
- Snapshot projection includes purpose-authorized self-reported context. Withheld medication/pelvic content is removed before private projection. A reported-not-taken/prescribed/planned/unknown exposure does not contribute an ingested dose or ingredient claim. Empty legacy condition lists do not establish the absence of disease. Source changes, correction, deletion or sharing revocation change the epoch; final source/evidence/permission recollection rejects stale output. Existing sleep/hydration/activity projection remains intact.
- Legacy precision reports omit the new GI payload and server mutation metadata. Shared context views omit private investigation sharing controls. No fixture, private output, model result or unreviewed claim is promoted to shared science.
- Private runner supports a bounded optional challenge pass only for an adapter explicitly supporting it. Both passes share one original deadline. After authorization, sources/evidence are freshly recollected before every invocation and compared with the original epoch; final recollection and grounding still follow every pass. This prevents a scoped-sharing revocation during between-pass authorization from sending the old scoped snapshot into another invocation. It requests competing explanations and explicitly rejects causal inference from proximity, historical dose inference from medication lists, and unreviewed taxa as SIBO/IMO diagnoses. These instructions and reference checks are **not a semantic or scientific truth verifier**.

### Nested exposure timing qualification

Private exposure projections now carry an explicit temporal context relative to the snapshot as-of clock, retaining source precision and the original effective field. Timestamp offsets are compared as recorded. Date-only events use a recorded source zone when available; the selected display zone is never substituted. An unknown-zone date stays unresolved unless it is beyond even the next UTC calendar day, a conservative calendar bound rather than a biological window or invented occurrence timestamp.

A future-dated reported-use/change event (or unusable source time) is flagged for timing review. Its dose and label-ingredient fields are withheld from that private projection so they cannot be mistaken for a current dose attributable to the future event; the canonical values, user-reported use status, event IDs and source revision remain untouched and available in the owned source record. This does not assert the person took nothing, establish a current regimen, diagnose an adverse effect, or convert event dates into pharmacological activity. Planned, prescribed-only, not-taken and unknown-use records continue to omit dose/ingredient claims. Missing time remains unknown, not a fabricated clock or normal status.

Six new local timing cases plus existing snapshot/private-runner/encrypted-pipeline controls pass (26 tests), including unchanged reads, a real source-time boundary, no source mutation, explicit source-zone dates and an unknown-zone near-boundary case. TypeScript, scoped snapshot compilation and the capability crosswalk pass. No UI, canonical schema/store, timeline, external provider, clinical action or infrastructure is added; fixtures and detailed receipts remain isolated outside Git. This remains source qualification, not scientific or consumer acceptance.
