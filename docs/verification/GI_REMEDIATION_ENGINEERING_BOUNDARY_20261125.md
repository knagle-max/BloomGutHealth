## Implemented source and privacy boundaries

- `shared/gi-source-context.ts`: bounded typed self-reported GI context, event-time precision, condition assertions, actual-use status, source mutation metadata and separate medication/menstrual-pelvic investigation sharing scopes.
- `server/precision-storage.ts`: encrypted canonical writes/corrections; source and sharing revision comparison; account-bound idempotency; scrubbed same-row deletion marker prevents replay resurrection without changing allowed database kinds. Account clearing removes source records and the sharing revision. Generic context updates preserve privacy choices and cannot grant them.
- `server/precision-routes.ts`: existing authenticated/no-store router owns source access and strict commands. Server metadata cannot be supplied by clients. Source edits preserve existing measurements and stable context event IDs supplied with the corrected record.
- Existing Biology response form: optional GI capture, default-off sharing controls, source review and typed correction of existing symptom, bowel, medication/supplement, condition, warning, weight-loss and pelvic context. Complete typed context correction is supported by the owned source API; the UI preserves stable symptom/exposure/condition IDs, unrendered fields and reported time precision. Removing the final reported condition requires an explicit unknown/none-reported assertion. Absent sections/new events use the existing optional capture path; this does not create another tracker. No mandatory questionnaire. Existing female reproductive UI eligibility is retained; pelvic observations do not infer a cycle phase.
- Snapshot projection includes purpose-authorized self-reported context. Withheld medication/pelvic content is removed before private projection. A reported-not-taken/prescribed/planned/unknown exposure does not contribute an ingested dose or ingredient claim. Empty legacy condition lists do not establish the absence of disease. Source changes, correction, deletion or sharing revocation change the epoch; final source/evidence/permission recollection rejects stale output. Existing sleep/hydration/activity projection remains intact.
- Legacy precision reports omit the new GI payload and server mutation metadata. Shared context views omit private investigation sharing controls. No fixture, private output, model result or unreviewed claim is promoted to shared science.
- Private runner supports a bounded optional challenge pass only for an adapter explicitly supporting it. Both passes share one original deadline; each is followed by fresh authorization, source/evidence recollection and grounding. It requests competing explanations and explicitly rejects causal inference from proximity, historical dose inference from medication lists, and unreviewed taxa as SIBO/IMO diagnoses. These instructions and reference checks are **not a semantic or scientific truth verifier**.
