## Material findings

### SCI-FINAL-01 — 25-OH versus 1,25-dihydroxy vitamin D assay identity: scoped P0 scientific safety correction
- **Screen/code:** `client/src/components/LabMarkerEducation.tsx`, rendered by LabExplorer; `shared/biology-labs.ts` and `shared/data/biology-content-r4m1-v2.json` for `vitamin_d`.
- **Verified source-level defect:** `const assayUncertain=profile.assayIdentityRequired&&!/25[\s-]*(?:oh|hydroxy)|1\s*,\s*25|dihydroxy/i.test(point?.method||'');` treats a method string containing `1,25` or `dihydroxy` as a **confirmed assay**, so it does not withhold source-range high/low context for the wrong vitamin D metabolite. The editorial text correctly states that 1,25-dihydroxy and 25-hydroxy tests are not interchangeable, making the acceptance check internally contradictory. Any accepted record with `marker=vitamin_d`, numeric source range, and method `1,25-dihydroxyvitamin D` or merely `dihydroxy` can bypass the 'confirm assay' restriction.
- **Impact:** Someone may read a 1,25-dihydroxy source value as if Bloom's 25-OH vitamin D status profile applies. Potentially misleading nutrient/clinical interpretation. **Observed in reviewed source; not independently reproduced in live browser or proven reachable from a particular provider importer.** Severity P0 **for vitamin-D interpretation**, not evidence of a whole-app defect.
- **Minimum correction:** First verify that the recorded analyte identity truly maps to supported `25-hydroxyvitamin D` rather than using a method-token regular expression as approval. Explicitly disallow 1,25-dihydroxy, 1,25-(OH)2, calcitriol or generic `dihydroxy` for the `vitamin_d` status interpretation; treat missing/ambiguous identity as unknown while retaining the exact source value/units/date. Do not infer assay from a numeric interval or unit alone. Add adversarial fixture test: confirmed 25-OH passes, 1,25-dihydroxy and ambiguous/blank method abstain; source record unchanged. If the importer itself can map a verified 1,25 assay to `vitamin_d`, add an upstream identity guard. Inspect source ranges and unit family for compatibility.
- **Original requirement:** BIO-LAB-201–207; lab source and unit fidelity, clinical interpretation abstention; Architect R4/M1 `What this might mean` identity/assay requirement.
