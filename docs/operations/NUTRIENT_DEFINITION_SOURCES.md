## Captured generic composition source snapshot

New reviews capture the actual selected local generic USDA per-100g values at the calculation boundary, directly from the planning/logging source record or FNDDS record used. Each versioned snapshot carries source ID/URL/version, ingredient, reviewed grams, definition version and explicit unknown collection date. Values retain native source precision, source field units and supplied form/activity basis. Missing/invalid values stay unknown/null; a source0 is separately flagged as source-reported zero and still marked an estimate. It never becomes an independently verified biological zero. No new nutrient totals or equivalent conversions are computed.

`mealReviewRevision` binds the complete raw snapshot as well as existing amounts/source facts. A source change below displayed precision invalidates an unconfirmed save; the existing completed receipt still replays its original frozen meal after later catalogue changes. Stored snapshots are never recreated by looking up today's data. Existing private label snapshots remain the authority for label context; live/other-provider source-native capture is not asserted. When replacement provider totals are used, partial local generic snapshots are removed from this active metadata to avoid misleading attribution.

The existing forms/units disclosure displays original captured values and source links within the same two deliberate interactions, with original units and per100g basis clearly distinguished from the reviewed portion. Strict bounded schema checks enforce source URL/ID, unique fields, numeric/null and source-zero consistency. Unsupported/legacy source views explain unavailability while preserving original saved estimates/labels. No new source collection date, actor permission, clinical effect, verified absorbed amount or canonical supplement ingestion is inferred.
