## Implemented scope

`shared/viome-pdf.ts` bounds files to8MiB/20pages/180ktext characters/40kitems/30s. The dedicated PDF.js worker extracts page text geometry only, never renders original pages or reads metadata/attachments. Coordinate reconstruction handles up to three actual columns, adjacent paired cells and wrapped strain suffixes; it does not divide the page into fixed thirds. Provider/report headings select the organism vs health/foods adapter; page count alone cannot classify a report. Biological dates require explicit collection/received/reported labels and exact calendar validation; absent dates/specimen/method remain unknown. Unsupported, textless/scanned, protected, corrupt, ambiguous and excessive inputs fail with fixed safe errors.

Only typed biological rows/positions and allowed dates/method cross to preview. Headers/footers/identity-labelled text are excluded; no raw original bytes, filename, original SHA, full page text, XMP or provider identifiers enter the source object. Cancellation/unmount/actor change terminates local work; buffers/worker/page references are cleaned best-effort, without claiming managed-memory erasure. No PDF POST/multipart/spooling occurs in this browser path. The server continues to receive existing strictly typed findings, not original PDF bytes.

The upload page accepts PDF directly, hides the identifying filename and replaces the disabled input stage with `Review your Viome report`. Preview shows totals/category counts, biological dates, searchable/paged source rows and provenance. Per-row biological label/category corrections retain the exact original label/category and position in existing Viome findings; canonical display uses the correction. While a row draft is open, other row navigation and confirmation/save are blocked until Apply/Cancel. Corrections clear review affirmation. One explicit review checkbox and Save use the existing owned, atomic receipt flow. JSON/CSV remains optional and its existing source-only journey passes.

Original source fields are immutable within the reviewed source object (`name`, `reportedCategory`, `position`); additive `correctedName` / typed `correctedCategory` carry reviewed corrections. Unknown fields remain rejected; no free metadata/raw-document bag was added. No numerical abundance, score calibration, toxin, allergy or personal mechanism is generated.
