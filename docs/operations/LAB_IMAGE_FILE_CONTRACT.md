# Local report-image transcription

The optional “Read text from a report image” disclosure in Add lab results reads one English PNG/JPEG on the device. It feeds the existing editable source-text review, not automatic clinical confirmation. Compare the original image with every decimal, symbol, unit and column; enter source date/context, preview, resolve source-only or provisional-unit rows, then explicitly save. Report identifiers and dates are never inferred from filenames. Scanned PDFs need an image export or manual entry; existing text-PDF/CSV/TSV/TXT readers remain available.

Limits before decoder allocation: nonempty file up to 5 MiB, matching PNG/JPEG extension and signature, valid dimension header, at most16 megapixels and10,000 pixels per side. Recognition has a60-second deadline; extracted text must be nonempty, at most30,000 characters, without binary/control/replacement characters. No truncation. Invalid, blank, oversized, failed or cancelled reads retain the previous draft. A replacement file wins over a late result.

A dedicated module worker owns the OCR child worker so cancellation also stops initialization. Replacement, timeout, unmount and account changes terminate both workers. The original image stays in browser memory behind a component/account-scoped object URL, revoked on replacement/new import/unmount. It is not uploaded or persisted. Only explicitly reviewed transcription enters the existing account-bound atomic importer, source-match checks, immutable source history and encrypted storage. No new endpoint, schema, capture enum or verified assay assertion is introduced.

Tesseract.js7.0.0/core7.0.0/English1.0.0 assets are pinned and self-hosted under client/public/ocr/v1 with original bytes, licence notices and SHA-256 receipts. Paths are explicitly same-origin, LSTM only, with no persistent OCR cache or CDN fallback. Model assets load on demand. This is source transcription software, not a clinically validated model; no external medical connector, clinical interpretation, provider activation or registry approval is granted.

Evidence: lab-image-file.test.ts covers format/bounds/exact text/zero/error privacy/abort/deadline/late reads; lab-image-assets.test.ts verifies21 original asset and notice receipts. The real App/Express/encrypted-PGlite lab-image-intake-journey.mjs runs the actual model on synthetic PNG and JPEG: zero,3.20,raw threshold/reference, explicit review before write, encrypted owned save, original-image comparison, replacement, blank input, cancellation during actual model initialization, deadline, navigation and pending account switch. CDP checks both worker levels terminate; requests stay same-origin asset GETs, with no image upload. Production-build mode is supported. Synthetic Chromium coverage does not establish real-report layout/accuracy, physical-device performance, VoiceOver or independent clinical/Design/Legal acceptance.

Rollback: revert the code/assets/dependency commit and rebuild. No migration or historical record rewrite; already reviewed stored source text remains valid existing input.
