# Complete AI Development Prompt for Bloom - Gut Health App

## Context & Overview

You are tasked with building “Bloom” - a comprehensive gut health and microbiome analysis application. This is a mobile-first web application that combines microbiome data analysis, food/symptom tracking, and AI-powered insights to help users optimize their gut health, identify food triggers, and receive personalized dietary recommendations.

## Core Business Requirements

### Primary User Problem

Users with IBS, digestive issues, and gut health concerns need to:

1. Understand their unique microbiome composition
1. Identify foods that trigger symptoms
1. Receive personalized recommendations to improve gut health
1. Track progress over time with data-driven insights

### Solution Approach

An AI-powered application that:

- Analyzes microbiome test data against optimal reference populations
- Tracks daily food intake and correlates with symptom patterns
- Uses advanced AI to identify trigger foods and recommend interventions
- Provides actionable, science-based recommendations for gut health improvement

## Technical Architecture Requirements

### Platform: No-Code Development

**Primary Tool**: Bubble.io (visual web application builder)
**Backend**: Firebase (Authentication + Firestore database)
**AI Engine**: OpenAI API (GPT-4 or GPT-4o-mini)
**Design**: Mobile-first, responsive design (375px base width, max 400px)

### Technology Stack Specifications

```
Frontend: Bubble.io visual builder
Database: Firebase Firestore
Authentication: Firebase Authentication (email/password)
AI: OpenAI API with custom prompts
Analytics: Google Analytics 4
Hosting: Bubble.io managed hosting
```

#### Data Sources & Calculations

```
Gut Score Calculation:
- Diversity Score (25 points): Based on bacterial diversity
- Beneficial Bacteria (25 points): Akkermansia + Bifidobacterium percentages
- SCFA Producers (25 points): Butyrate-producing bacteria
- Symptom Impact (25 points): Inverse of average symptom severity

Day Streak: Count consecutive days with food entries
Trigger Foods: Count of foods with >70% symptom correlation
```
