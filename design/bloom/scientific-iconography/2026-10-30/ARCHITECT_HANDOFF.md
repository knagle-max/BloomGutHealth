**Dependencies:** Clickable Microbial Composition Profiles (UT-TAXON-2801–2808; BIO-TAXON-2901–2905), Biology/Progress UX (UT-BIOPROG-2901–2907; BIO-BIOPROG-3001–3004), flagship visual direction; avoid duplicating existing research profiles.

## Decision requested
Approve a **restrained scientific iconography layer**: elegant microscopy-inspired *illustrative portraits* for microbes, chemically accurate molecular graphics for molecules, and functional restrained icons for bloodwork. Build discoverable scientific identity without misleading exact taxon identification, molecular structure, specimen imaging, clinical status or evidence strength.

## Requirements / priorities
- **MKT-VISBIO-3201 (P1)** — Single iconography system. Compact 32–40px organism thumbnails in lists, 120–220px hero portraits in expanded organism research profiles. Common palette (Bloom evergreen #246B50, off-white, indigo/blue highlights as needed), natural-history / scientific editorial mood, subtle lighting and disciplined composition. No smiling anthropomorphic bacteria, cartoon pathogens or green/red good/bad creatures. Image is secondary to organism name/measurement.
- **MKT-VISBIO-3202 (P0 truthfulness)** — Source-backed depiction semantics. Organism visuals must be labeled **Illustration** or **Representative micrograph** with taxon resolution, source, provenance, license and accuracy limitations. Morphology at species/strain level often cannot be uniquely inferred from appearance. Never claim generated art depicts a real microscopic image or precise named strain; avoid invented organelles, flagella, envelopes, colony types, staining, scale bars or relative sizes. Expert review of shape and type before launch.
- **MKT-VISBIO-3203 (P1)** — Optional **Illustration / Under the microscope** toggle only when an actual high-quality scientifically identified, licensed micrograph for that taxon and resolution is available. If none, show illustration with honest label; no fake microscope option. Cite specimen/method, scale bar only where source-provided, image credit/licence.
- **MKT-VISBIO-3204 (P1)** — Accurate molecule assets. Render verified 2D structural formula and optional 3D ball-and-stick / space-filling views for approved molecules (initial candidate: butyrate/butyric acid, acetate/acetic acid, propionate/propionic acid, lactate/lactic acid). Preserve ionization, protonation, chirality and pH context; avoid casually equating conjugate acid and anion. Chemistry specialist verifies structure, atom bonds and caption against reputable reference; graph/accessibility fallback mandatory. Do not imply molecule detection or level in user's personal sample.
- **MKT-VISBIO-3205 (P1)** — Progressive discovery journey: from taxon composition row → portrait and profile → studied substrate/products and claim-level evidence → molecule profile/structure → sourced pathway and back; navigation retains selected original report, date, percent and scroll. Connection types indicate studied association/potential rather than personalized metabolic measurement. No conversion into microbial abundance target or treatment.
- **MKT-VISBIO-3206 (P1)** — Bloodwork restraint. Keep LabTrend and numeric/date hierarchy dominant; category glyphs only, no biomarker cartoon illustrations or judgmental badges. No visualization overlays implying result normality/urgency without validated lab-specific review.
- **MKT-VISBIO-3207 (P0/1)** — Accessible and performant: icon alternatives describe meaning if meaningful; decorative art has empty alt; name/number/state remain textual. Keyboard controls and screen reader headings; 320px, 200% zoom, dark/light, reduced motion; mobile responsive image sizes, progressive loading, CDN-compatible local thumbnails, no third-party page trackers or remote image beacons.
- **MKT-VISBIO-3208 (P0)** — Rights/asset governance: each approved graphic requires stable ID, taxonomy or molecule identifier, variant/resolution, art-vs-micrograph provenance, original source, license and redistribution/commercial-use rights, attribution location, reviewer, review date and version, expiry/withdrawal fallback. Commercial permission verified before embedding imagery. Do not copy web image results into app without rights.
- **MKT-VISBIO-3209 (P1)** — Pilot & validation: 3 distinct morphology-informed organism portraits (including archaeal example where supported), 3 structurally verified molecular models, list + detail + science-pathway states. Test identity mismatch, morphology overclaim, micrograph rights, dark/light, text-only/offline, mobile performance and 5-person comprehension: can users distinguish illustration vs actual micrograph, research possibility vs measured personal output, and acid vs anion when relevant? Pilot results must be reported, not presumed.
- **MKT-VISBIO-3210 (P0 delivery)** — Developer imports native editable source and UX contracts from this branch after Architect approval; test and render implementation; return exact SHA, licensing register and screenshots. Designer signs off visual fidelity, Biology & domain experts scientific statements, Legal image rights, Developer implementation.

## Release sequence
1. Source metadata model, license checklist, design semantics, fallback states.
2. Pilot organism portraits and molecule structures reviewed by Biology/chemistry (start with placeholders, not fake species-specific science).
3. Add compact list portraits and expanded profile visuals using existing organism profile components.
4. Interactive molecule view and optional licensed micrograph toggle.
5. Expand coverage only where reference and license review complete. Missing art must never block core biology/report access.

## Acceptance scenarios
(a) Unillustrated taxon → plain name and generic icon, never inaccurate unique cell. (b) Named taxon with verified illustrative morphology → visually distinguished but labeled illustration. (c) Micrograph missing rights → toggle absent. (d) E. coli at species level → no virulence or strain label from image. (e) Methanobrevibacter smithii recognized as archaeon. (f) Butyric acid versus butyrate chemically distinguished. (g) No uploaded microbiome → research explorer works without false personal values. (h) Screen reader, reduced motion, offline, dark-mode and tiny viewport meet task criteria.
