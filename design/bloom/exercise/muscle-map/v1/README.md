# Bloom exercise muscle map artwork

21 individual source-editable, transparent SVG region illustrations with named muscle group emphasis. Front/back neutral anatomical silhouettes use consistent geometry and Bloom green highlighting. Raster PNG variants at 128px and 256px should be exported from these exact SVGs; do not substitute generative PNG reference boards for source assets.

**UI rule:** show muscle involvement in Athlete mode, not Everyday. Muscle maps are curated educational associations only, never measured activation, injury, fatigue or recovery. User-entered sets, reps, loads and completion remain editable in both modes from one canonical workout. Primary/secondary classification comes from separately reviewed exercise-ID mapping, **not from the image**.

The reference artwork boards generated earlier are composite PNGs, not independent reusable icons. The isolated source SVGs are original vector design derivatives built for this asset bundle. Legal/QA approval remains pending.
