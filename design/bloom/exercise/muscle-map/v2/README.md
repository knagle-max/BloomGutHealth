# Bloom — high-detail exercise anatomy artwork v2

This delivery preserves the original user-approved premium anatomical illustration style. Ten named muscle-category tile exports, ten art-only crops, ten 512-pixel screen-ready renditions, and original front/back full-body references. These are actual raster images, **not** flat SVG replacements.

**Important:** Backgrounds are intentionally retained to preserve fine cream-coloured anatomical detail. They are not transparent. A responsible transparent anatomical export requires generating / separating the actual layered illustration rather than chroma-keying the pale muscle tissue (which damages its texture).

**Developer guidance:** Use the art-only PNGs for cards, the full-body front/back images for reference views, and programmatic labels in the UI (do not rely on labels baked into images). Use web-optimized PNG/WebP and responsive `srcset`; avoid raster scaling above available native detail. Display muscle diagrams and mapped involvement in Athlete only, retaining all editable sets/reps/weights in Everyday. Image highlight != measured activation, injury or recovery state. Map exercises using separately reviewed and versioned exercise IDs, primary/secondary regions, and technique limitations.

**Do not use:** prior `design/bloom/exercise/muscle-map/v1/svg/` as primary visual art; it is a superseded flat design draft. Original anatomical sources and commercial provenance still need standard product documentation.
