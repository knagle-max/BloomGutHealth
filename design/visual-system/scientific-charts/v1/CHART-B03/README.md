# CHART-B03 — Two-result comparison and reference reveal

Production **editable design assets** for Bloom v0.6; not a ready-to-use chart image and not a claim of deployed acceptance. 96 responsive SVG specimens: 4 modes × 4 widths (320,390,768,1440) × 6 scenarios. Eight full editable SVG masters, CSS and JSON contract. Specimens deliberately include **fictional** measurements only; never deploy them as personal results.

Scenarios: comparable; non-comparable assay/method; measured zero baseline; source interval unavailable; changed method/source interval; withdrawn source.

The developer renders source measurements, comparison eligibility, calculations, reference bands, dates, units, data points and interactions dynamically. Source interval reveal may not imply a universal healthy band or project a selected-point interval onto unrelated history.

**Fidelity:** difference = later minus earlier only if comparable; percent change only when a valid non-zero earlier value exists; a legitimate measured zero is distinguished from unknown. No claims of causality. Revoked source content must not be exposed.

**Review:** Science validates comparability, ranges and source semantics; Structural UX validates tappable origin and accessible table; Architect authorizes integration; Designer validates actual 320/390/768/1440 screens across Everyday/Athlete light/dark after Codex renders them. No runtime claim is made.
