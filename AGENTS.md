7. **Low-overhead delivery:** Select one smallest high-value currently eligible slice, establish actual code and failure/task evidence, implement with source-safe review, focused tests and appropriate typecheck/build; run broad regression for shared high-risk boundaries or integrated checkpoint, not every cosmetic edit. Do not routinely generate before/after screenshots or mandatory viewport screenshot sets. Actual rendered quality/browser checks still matter; report `NOT_TESTED` when omitted. Commit scoped nonpersonal changes and provide exact-SHA/test receipt. Never blindly reset/rebase/push unrelated work. If a specific blocker cannot be safely resolved, record it and move to the next eligible independent task.
